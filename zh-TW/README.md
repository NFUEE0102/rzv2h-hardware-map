# RZ/V2H 全板硬體資源地圖

語言：[English](../README.md) · 繁體中文（本頁）

這是一份從零開始、每件事都自己查證的地圖：Renesas RZ/V2H RDK 開發板
（SoC 料號 R9A09G057H44GBG，即 RZ/V2HP 版）上到底有哪些硬體、每一項處於什麼
狀態，以及你要怎麼自己動手確認那個狀態——不必聽信任何人的說法，包括這份文件
本身。

本資料夾收錄的是**中文原稿**，也就是英文版翻譯所依據的來源；英文版在
[上一層](../README.md)。

## 為什麼有這份東西

這是**前置閱讀，不是教學**。在你拿這塊板子做任何東西之前——相機管線、即時控制
迴圈、自製驅動程式——你需要一份誠實的清單：哪些東西真的開著、哪些在矽晶上但
沒有接到 Linux、哪些在這個料號上根本沒有搭載。這份清單弄錯是會實際浪費時間
的：去追一個永遠不會出現的 `/dev` 節點（因為它對應的硬體不在這顆矽晶上），
或是把「找不到」當成故障，而其實那正是正確、預期中的答案。

這份倉庫的設計，是讓你在上這塊板子的實作課或工作坊**之前**先讀完，好讓實際的
授課時間花在有意思的部分，而不是重新推導一次「我們到底有哪些硬體」。

## 核心觀念：「我找不到它」有六種成立的方式

這是整份地圖裡最有用的一個概念，每一個檔案都一致地使用它：

| 狀態 | 意義 | 該怎麼看待 |
|---|---|---|
| **啟用** | device tree 標 `okay`、Linux 驅動程式已綁定、有可用的 `/dev` 或 sysfs 節點 | 拿來就能用 |
| **部分啟用** | 同類硬體有多個實例，device tree 只把其中一部分標成 `okay` | 開著的那些可用，其餘要改 DT |
| **存在·Linux 未曝露** | 矽晶上有這顆硬體，但執行中的 Linux 沒有對應的驅動程式節點——只能靠韌體（u-boot／CM33／CR8）或外部探針動它 | 不是壞掉，只是「不歸 Linux 管」 |
| **保留** | 硬體是啟用的，但整塊已被開機韌體／remoteproc／記憶體 carveout 占走，從未加進 Linux 的一般記憶體池 | 存在，但不開放挪用 |
| **停用** | device tree 明確標成 `disabled` | 要改 DT **而且**實體硬體有接上，才會活過來 |
| **未搭載** | 這顆矽晶（R9A09G057**H44**）根本沒有這個模組，是別的料號才有 | 別找了，這顆晶片上沒有 |

這份倉庫裡每一句「我找了 X 但沒找到」，最後都會落到這六格的其中一格；每個檔案
都會告訴你是哪一格、以及為什麼。

## 這份倉庫裡**沒有**的東西

每個檔案都會引用兩份內部調查文件（行文中稱為「doc06」與「doc07」）以及一批
板上查證的原始 transcript，它們都沒有收錄在這裡——這些引用是留作**出處**用的
（「這個數字來自實測，不是猜的」），而不是要你去點開的連結。凡是直接對照
Renesas 官方硬體手冊或 datasheet 查證過的主張，引用會明講（手冊節號、頁碼
範圍）；凡是從那些內部文件轉錄、未獨立回查原頁的，也一樣會標示出來——這份地圖
在「我自己讀過」與「別人的筆記這樣說」之間劃了一條硬性而誠實的界線。

Renesas 官方文件本身（`r01uh1032` 硬體手冊、`r01ds0429` datasheet）沒有收錄
——那是 Renesas 的著作權資料。[99-官方文件查閱指路](99-official-documentation-guide.md)
會告訴你該找什麼、去哪裡找。
